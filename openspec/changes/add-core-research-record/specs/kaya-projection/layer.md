# kaya.projection — dual-format layer (sidecar)

## Purpose

Documentation as a compilation: deterministic, incremental, with source
maps back to evidence. The managed-block grammar is the contract that lets
documents stay live — generated sections track the ledger while authored
interpretation survives untouched — and stale flagging is what replaces the
silent drift that motivated kaya: the human finds out their interpretation
rests on changed evidence, instead of never finding out.

## Constraints

| id                       | kind      | expr                                                                                                                                                                                              | traces_to |
|--------------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------|
| managed_grammar          | invariant | `generated content appears only between kaya:begin/end generated:<name> markers; authored content only between kaya:authored / kaya:end authored markers`                                             | [[kaya.projection.layer]] |
| authored_byte_preserved  | invariant | `regeneration leaves every non-generated byte identical — authored blocks, uncategorized prose, and foreign tools' managed blocks included`                                                            | [[kaya.projection.layer]] |
| generated_deterministic  | invariant | `identical (ledger, graph, template) state yields byte-identical generated sections — no generation timestamps, no map order, no locale formatting inside blocks`                                        | [[kaya.projection.layer]] |
| incremental_scope        | invariant | `a rebuild recomputes exactly the projections whose inputs appear in the event frontier; unchanged-input projections keep their previous bytes without recomputation`                                     | [[kaya.projection.layer]] |
| stale_flagging           | invariant | `when evidence cited by an authored block changed since its last acknowledgment, the build summary reports the block stale naming the changed ids — the block's bytes are never altered; acknowledgment is a human-recorded event` | [[kaya.projection.layer]] |
| source_map               | invariant | `every fact in a generated block traces to named event ids in the build's source map`                                                                                                                  | [[kaya.projection.layer]] |
