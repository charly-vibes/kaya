MVP-1 implementation contract (orchestrated 2026-11-16). (1) Module layout: src/{envelope,event,ledger,model,promotion}.rs, src/adapters/{mod,wai,git,testrunner}.rs, src/projection/{mod,index,report}.rs; bin+lib crate, integration tests per capability. (2) CLI I/O is a local minimal genesis-style envelope (no genesis-vibes dep): ok/envelope_version 0.1/cli_version/envelope_kind/data/warnings/hints/meta/error, exit 1 on labeled error; ledger rows stay kaya.event/v0 (envelope_independence seam). (3) Ledger digest = SHA-256 over exact bytes; tamper localization via Anchor (per-line hashes) passed by the caller, because the git_versionable invariant forbids sidecar state; crash-tail truncated before reads. (4) Event type grammar requires >=3 dotted lowercase segments: model.entity.created, model.relationship.asserted, capture.artifact.observed, capture.commit.observed, experiment.run.completed, promotion.assertion.recorded, promotion.conclusion.established/challenged. (5) subject = {type,id}; entity ids are <project>/<TYPE>/<key>; adapter event ids are content-addressed from (tool, source reference) and timestamps derive from the source (commit time, artifact filename date, report mtime) so replay is byte-identical and deduped. (6) Closed-set refusal errors carry labels kaya.<capability>.<rule>; adapters emit no interpretation keys (verdict/conclusion/interpretation/hypothesis_status refused at capture).
