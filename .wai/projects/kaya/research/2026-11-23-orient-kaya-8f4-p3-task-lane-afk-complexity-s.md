DECISIVE EVIDENCE (reproduced, not inferred): the current behavior is not merely 'the shared gate is not applied' - a stale publication block SILENTLY SURVIVES. Fixture: docs/public/overview.md holding a block named 'publication.produkt.overview' (a misspelled tier). 'kaya publish' exited 0 and left the page carrying BOTH the stale misspelled block AND a fresh publication.product.overview block; 'kaya check' then reported drift [] and ok true - it did not notice. The reason is visible in the code: plan replaces only the block it names, and compare_publication compares bytes without classifying names.

Consequence for the decision: a documented exemption alone would bless a state where a page carries two publication blocks and no gate notices. The vocabulary must be enforced where publication pages are planned, not merely described.
