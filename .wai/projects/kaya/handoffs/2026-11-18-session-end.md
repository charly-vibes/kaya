## Gotchas & Surprises

- `turu recall` returns multiline entries truncated at the first blank line; the full body must be read from the branch notes section.
- `ah scenario new` refuses scenarios that already exist in a spec, so contract files for existing prose scenarios must be authored in the deployed format.
- `openspec archive` does not copy layer.md sidecars; they must be placed beside the deployed spec.md or spk lints nothing.
- Deployed specs collided on one slug only after archiving; the change overlay does not report slug-collisions.
- `ah archive <change>` is a separate spectacular command that deploys contracts and removes the change contract directory.
- `just` recipes cannot use `$$` shell variables (they expand to the PID); a python helper was the safe path.
- wai pipeline gate artifacts are tagged with the step active at creation time; a note recorded just before advancing tags as the previous step and does not satisfy the next gate.
- pretender's pre-commit gate reports ~50 pre-existing style-threshold violations and does not block commits.
